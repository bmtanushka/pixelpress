Best image sizes for websites: dimensions, file size and format

Updated October 19, 2026 · 2 min read

Short answer: Use WebP, size images to the largest width they're displayed at (about 1920 px for full-width banners, 1200–1600 px for content images, 300–600 px for thumbnails), and keep large images under about 200 KB and thumbnails under about 50 KB.

Why image size matters

Images are usually the heaviest part of a web page. Oversized images slow down Largest Contentful Paint (LCP), a Core Web Vitals metric Google uses for page experience — a good LCP is 2.5 seconds or less. Resizing and compressing images is often the single biggest speed improvement you can make.

Choosing a format

WebP is the best default: it's supported by all modern browsers and is typically 25–34% smaller than JPG. Use AVIF for even smaller files if your platform supports it, PNG only for graphics that need lossless quality, and SVG for logos and icons. See the format comparison guide for details.

Serve the right size to each screen

A phone doesn't need a 1920 px image. Use the HTML srcset attribute to offer a few widths (for example 640, 1280 and 1920 px) and let the browser pick. Add loading="lazy" to images below the fold, and always set width and height to prevent layout shift.

Step by step: how to optimize images for a website

1

Resize to the display size

Use Resize image with a maximum dimension of 1920 px for banners, or 1280 px for content images.

2

Convert to WebP

Choose WebP as the output format, with 75–85% quality for photos.

3

Check the file size

Aim for under 200 KB for large images and under 50 KB for thumbnails. If a file is still too big, use a target file size.

Frequently asked questions

What is the best image format for websites?

WebP for most images, AVIF where supported for the smallest files, SVG for logos and icons.

How many KB should a website image be?

As a guide, under 200 KB for large hero images, under 100 KB for content images and under 50 KB for thumbnails.

Does image size affect SEO?

Indirectly, yes. Smaller images make pages load faster, which improves Core Web Vitals and user experience. Descriptive file names and alt text also help images appear in Google Images.
