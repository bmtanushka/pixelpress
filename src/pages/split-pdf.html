How to split a PDF

1

Add a PDF

Drop a PDF onto the box above. Every page is shown as a thumbnail.

2

Choose pages

Click thumbnails to select them, or type pages and ranges like 1-3, 5, 8-10 and click Select these.

3

Extract or split

Extract selected creates one new PDF. Split by ranges creates one PDF per range, and Split every page creates one PDF per page — both as a ZIP.

Three ways to split a PDF

Extract selected saves the pages you've chosen into one new PDF — perfect for sending just the signed page of a contract. Split by ranges turns each comma-separated range (for example 1-3, 4-6) into its own file. Split every page saves each page as a separate PDF.

The original file is never changed, and nothing is uploaded.

Frequently asked questions

How do I extract one page from a PDF?

Add the PDF, click the page's thumbnail to select it, and click Extract.

How do I split a PDF into multiple files?

Type ranges like 1-5, 6-10 into the box and click Split by ranges. Each range becomes a separate PDF in a ZIP.

What does 8- mean?

A range with no end, like 8-, means from page 8 to the last page.

Does splitting reduce quality?

No. Pages are copied exactly as they are.
