KB, MB, pixels and DPI explained: what "image size" really means

Updated October 19, 2026 · 2 min read

Short answer: File size (KB or MB) is how much storage the image takes. Dimensions (pixels, e.g. 1920 × 1080) are how many dots it contains. DPI only matters for printing: it says how many pixels are printed per inch. You change file size by compressing, and dimensions by resizing.

File size: KB and MB

File size is measured in bytes. 1 KB (kilobyte) is 1,024 bytes and 1 MB (megabyte) is 1,024 KB. Some systems use 1,000 instead of 1,024, which is why sizes can differ slightly between devices. When a form says "under 50 KB", it means the file on disk must be smaller than that.

Dimensions: pixels

A digital image is a grid of pixels. A 12-megapixel phone photo is about 4000 × 3000 pixels. More pixels mean more detail — and a larger file. Halving both width and height cuts the number of pixels to a quarter.

DPI and print size

DPI (dots per inch, often used interchangeably with PPI) connects pixels to physical size: print size in inches = pixels ÷ DPI. A 600 × 600 px photo printed at 300 DPI is 2 × 2 inches. Screens ignore the DPI value, so changing DPI alone doesn't change how an image looks online or its file size.

Step by step: how to change an image's file size and dimensions

1

To reduce file size

Use the image compressor or Compress to KB. Lower quality and modern formats like WebP reduce KB without changing dimensions.

2

To change dimensions

Use Resize image (maximum size) or Resize to exact pixels (width × height).

3

To prepare for print

Multiply the print size in inches by 300 to get the pixels you need — for example, 4 × 6 in at 300 DPI is 1200 × 1800 px.

Frequently asked questions

Does changing DPI reduce file size?

No. DPI is just a label for printing. To reduce file size, compress the image or reduce its pixel dimensions.

How many KB is a 1920 × 1080 image?

It depends on the content and format. A typical photo at 80% JPG quality is 200–500 KB; as WebP it's often 25–35% smaller.

What does megapixel mean?

One megapixel is one million pixels. A 4000 × 3000 photo has 12 million pixels, so it's 12 megapixels.
