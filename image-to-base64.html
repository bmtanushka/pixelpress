What is a Base64 image?

Base64 encodes binary data, such as an image, as plain text. A data URI like data:image/png;base64,… lets you embed an image directly in HTML, CSS or JSON without a separate file request.

Base64 makes files about 33% larger, so it's best for small images like icons, logos and email graphics — usually under 10 KB. For larger images, a normal file with caching is faster.

Frequently asked questions

When should I use Base64 images?

For small icons, logos and email graphics where avoiding an extra file request helps. Avoid it for large photos.

Why is the Base64 string larger than the file?

Base64 uses 4 text characters for every 3 bytes, adding about 33% to the size.

Can I convert Base64 back to an image?

Yes — switch to the Base64 → Image tab, paste the string and download the image.
