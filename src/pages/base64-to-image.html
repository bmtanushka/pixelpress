Decoding Base64 images

Base64 strings often appear in HTML, CSS, JSON API responses and email source code. This tool turns them back into real image files you can open and save.

It accepts full data URIs, plain Base64 and URL-safe Base64, ignores line breaks, and detects the real image format from the file signature rather than trusting the label.

Frequently asked questions

What does a Base64 image look like?

It usually starts with data:image/png;base64, followed by a long string of letters, numbers, + and /. PNGs start with iVBORw0KGgo and JPGs with /9j/.

Why does it say the data isn't an image?

The string may be incomplete, or it may encode something other than an image. Make sure you copied the whole value.

Is my data sent anywhere?

No. Decoding happens entirely in your browser.
